# Сервис хранения файлов и управлениями ими

### Рарешения:
Всего есть 2 типа разрешений в формате jwt:
1. Токен подтвержающий что создатель файла - мы (разрешение его использвать).

    ```json
    {
        "userCreated": 1,
        "fileId": 44,
        "exp": {instant}
    }
    ```
    * При истечении exp и неиспользоваемости файла, файл в file-service будет удален.

2. Разрешение просмотра приватного файла. 
    ```json
    {
        "fileIds": [4, 99, 12],
        "issuer": "identity-service",
        "exp": {instant}
    }
    ```
    * Токен разрешает разрешить сразу несколько файлов (file_ids).
    * Issuer - это поле рассказывающие нам о там, какой сервис выпутил данное разрешение.
